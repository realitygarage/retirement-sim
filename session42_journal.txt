Net Worth chart's expanded breakdown table was showing every-other-year

--- ROOT CAUSE ---

Chart component (App.jsx) samples its breakdown table to every-other-year by
default (`bdRows = (annualTicks||annualBreakdown) ? bdSource :
bdSource.filter((_,i)=>i%2===0||...)`) to keep wide tables from getting too
wide -- an opt-out per chart via the `annualTicks`/`annualBreakdown` props,
already used this way for the Work Income Required chart since v5.2.0. The
Net Worth <Chart> instantiation (App.jsx ~line 3026) never passed either
prop, so its table fell into the default biennial sampling.

--- FIX ---

Added `annualBreakdown` to the Net Worth <Chart .../> call -- same mechanism,
no new code path. One-line change plus version bump (v5.10.0 -> v5.10.1):
App.jsx header comment + on-screen badge, and the two version-string
Playwright assertions (E5, L1) updated to match.
