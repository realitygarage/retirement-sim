--- v5.17.0 (PART C): TYPED NUMBER FIELDS REPLACE EVERY SLIDER -- 9c1d3ed ---

- New module-level NumberField (module-level so an App re-render doesn't
  remount it mid-typing). Typed in display units via scale/offset; commits
  on Enter/blur only (Esc reverts) so intermediate keystrokes never re-run the
  sim; Up/Down = step, Shift = 10x; clamps to the old min/max on commit with a
  ~1.5s "max $X" hint; empty/non-numeric input reverts. Typed values are NOT
  snapped to step (so $1,856 works). Focus-then-leave without editing is a
  no-op (no rounding of values stored at higher precision).
- slider() keeps its signature + optional opts and renders it (all 49 calls);
  sliderTypeIn/propValueEdit retired. The 16 raw range inputs use numField().
- Bob's decisions: month pickers (Nolan deferment, LI loan start, both SS
  starts) became Jan-Dec button rows like sale month; $ fields type full
  dollars (Property value was $K; structure values stay STORED in $K,
  scale 1000); the property mortgage grid moved onto NumberField (it was
  committing every keystroke). Defaults tab (empty = reset to code value)
  and the Work Income Curve (already commit-on-blur) left alone.
- Bug found by the full run and fixed before commit: the focus handler's
  formatted->raw swap landed a beat late (React re-render), so a
  select-all-and-type right after focus APPENDED to the raw text
  ("525000"+"600000" -> clamped to max). Now swapped in the DOM synchronously.
- Tests: setSlider/setSliderExact reimplemented as type + Enter (call sites
  unchanged); A3, F1 (was range nth(9)), J5 (was an ambiguous near-match --
  now the 15th St property value field), S1 (was setting a Cash Flow tab
  field from the Simulator tab -- the fuzzy helper silently moved some other
  slider), S3/S5/S6, Group B/R sale year, Y/AB zoom, AE1. New Group AF
  (AF1-AF8: commit, Esc, clamp+hint, arrow nudge, intermediate digits,
  invalid revert, % scaling, month buttons).
- A1 REWRITTEN (Bob chose option 1): under current defaults keep% barely
  matters (0% vs 100% moves total sweep by ~$437 over the whole horizon, the
  badge rounds to $0) -- A1 only ever passed because the fuzzy near-helper
  moved a DIFFERENT slider. It now sets every Work Income Curve point to
  $8,000/mo first, then compares: keep 100% -> $0/mo sweep, $120K interest,
  clear 2037; keep 0% -> $970/mo, $57K, clear 2032.
